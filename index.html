口径说明

全局口径定义
  1. 所有计数字段统一按整数展示，包括总数、次数、页码、排名名次等。
  2. 所有金额字段统一按 USDT 口径展示，最多保留 8 位小数，末尾为 0 的小数位不展示。
  3. 所有未实现盈亏字段最多保留 8 位小数，末尾为 0 的小数位不展示。
  4. 所有时间字段统一展示为 `YYYY-MM-DD HH:mm:ss`。
  5. 交易对价格、持仓数量、持仓方向、开仓均价、标记价格、当前价等基础行情与持仓字段，以后端币对配置和后端实时返回结果为准，前端不自行推导真实结果。
  6. 平台最大可亏损额表示该币对在平台维度可承受的总亏损阈值，计算口径为：平台最大可亏损额 = 多仓亏损 + 空仓亏损。
  7. 当前多仓亏损与当前空仓亏损为展示字段，不在前端配置页录入，统一以后端风险结果返回为准。
  8. ADL 触发时，系统先比较当前多仓亏损与当前空仓亏损的绝对值，亏损更高的方向优先执行自动 ADL。
  9. 每完成一个用户在当前币对、当前方向下的全部持仓 ADL 后，系统需要基于最新亏损数据重新比较多空方向风险，并重新判断下一次 ADL 应处理的方向与用户。
ADL异常处理总则
  1. 自动ADL与手动ADL在执行前，均需校验当前持仓状态、是否存在挂单以及剩余可平部分是否满足本次ADL执行要求。
  2. 若用户持仓存在挂单，且剩余可平部分小于“持仓数量 × 币对配置中的单次减仓比例”对应结果，则需先撤销该用户相关挂单，再继续执行ADL。
  3. 若当前持仓状态为“已完成”，则该持仓不可继续ADL；自动ADL应跳过当前候选持仓并顺延下一名，手动ADL应直接提示用户不可执行。
  4. 持仓状态、挂单状态、剩余可平部分、最小开仓数量等执行前校验字段，均以后端实时返回结果为准。
顶部统计维度（日 / 周 / 月 / 总）
  1. 顶部“日 / 周 / 月 / 总”为全局统计维度切换项，默认选中“日”。
  2. “日”表示按当日自然日汇总顶部统计数据；“周”表示按当前自然周汇总；“月”表示按当前自然月汇总；“总”表示按系统当前可统计全量周期汇总。
  3. 该切换项统一作用于顶部数据概览卡片。
  4. 顶部新增“顶部统计币对”筛选，默认“全部”；选择具体币对后，顶部“减仓次数”和“用户ADL总盈亏”均按所选币对联动刷新。
  5. 减仓次数 = 当前筛选范围内用户减仓次数字段 `adlUsers.reduceTimes` 汇总结果；用户ADL总盈亏 = 当前筛选范围内 `adlUsers.realizedPnl` 汇总结果。
  6. 列表是否联动统计维度，以各列表自身口径定义为准，不因顶部切换自动改变字段结构。
输入项全局规则
  1. 所有输入框以后端接口校验和最终返回结果为准，前端仅负责录入限制、提示文案和页面展示。
  2. 百分比类输入项统一按百分比口径录入，默认支持最多 2 位小数。
  3. 币对价格、持仓数量、标记价格、当前价、开仓均价等行情与数量类字段，以后端币对配置和后端返回参数为准。
  4. 谷歌验证码统一为 6 位纯数字；长度不足 6 位、包含非数字字符或为空，均视为不合法输入。
币对配置
  1. 本页展示 ADL 盈利减仓的交易对级配置。
  2. 本页用途是定义触发阈值、单次减仓策略、统计周期和风控预警状态。
  3. 列表支持筛选和分页。
筛选输入项定义
  1. 搜索币对：支持输入交易对关键字，按包含关系匹配币对名称；空值表示不过滤。
  2. 状态：支持选择“全部状态 / 风险预警 / 正常”，默认“全部状态”。
  3. 点击“查询”后，列表按当前筛选条件过滤，并从第一页开始展示。
  4. 点击“重置”后，搜索币对清空、状态恢复为“全部状态”，并重新加载第一页。
平台最大可亏损额(USDT)
  1. 该字段表示该交易对在平台维度可承受的总亏损阈值。
  2. 计算口径：平台最大可亏损额 = 多仓亏损 + 空仓亏损。
  3. 当系统识别到总亏损风险超过该阈值时，触发对应减仓处置。
当前多仓亏损 / 当前空仓亏损(USDT)
  1. 当前多仓亏损表示该交易对在多仓方向当前累计亏损金额；当前空仓亏损表示该交易对在空仓方向当前累计亏损金额。
  2. 两个字段均以负数表示亏损，绝对值越大表示对应方向风险越高。
  3. 两个字段由后台风险结果返回，仅用于展示和风控判断，不在前端配置编辑页手工录入。
  4. 系统判断 ADL 方向时，先比较两个方向亏损绝对值，亏损更大的方向优先处理。
ADL减仓持仓单次比例
  1. 该字段用于定义自动 ADL 场景下，单次对目标持仓执行“全部减仓”还是“按比例减仓”。
  2. 固定选项为“全部 / 按比例”，默认取当前币对已保存配置；新增币对时默认“全部”。
  3. 选择“全部”时，表示单次 ADL 对当前用户在当前币对、当前方向下的可减仓持仓全部减仓。
  4. 选择“按比例”时，单次减仓数量 = 当前可减仓持仓数量 × 单次减仓比例。
  5. 若按比例计算出的减仓数量小于该币对最小开仓数量，则降级为全部减仓；最小开仓数量以后端返回为准。
已ADL减仓次数 / ADL盈余总盈亏(USDT)
  1. 已ADL减仓次数：表示该交易对在当前统计周期内已触发的 ADL 减仓总次数，展示为整数。
  2. ADL盈余总盈亏(USDT)：表示该交易对在当前统计周期内因 ADL 减仓累计产生的盈亏结果。
  3. ADL盈余总盈亏大于 0 表示平台侧盈余，小于 0 表示平台侧亏损。
状态
  1. 状态固定取值为“风险预警 / 正常”。
  2. 风险预警：表示该交易对当前风险接近触发线或已发生减仓事件。
  3. 正常：表示近期风险低于预警阈值。
配置编辑入口
  1. 点击“添加币对配置”或列表“编辑”进入独立配置编辑页面。
  2. 配置编辑不使用弹窗，使用独立页面承载长字段与多参数。
  3. 编辑页支持设置：交易对、平台最大可亏损额、多仓用户破产价偏移比例、空仓用户破产价偏移比例、ADL减仓持仓单次比例、重置周期。
多仓用户破产价偏移比例(%) / 空仓用户破产价偏移比例(%)
  1. 两项配置均用于按触发时市场价格推导用户破产价。
  2. 多仓用户破产价 = 市价 × (1 - 多仓用户破产价偏移比例)。
  3. 空仓用户破产价 = 市价 × (1 + 空仓用户破产价偏移比例)。
  4. 配置值按百分比理解，例如输入 5 表示 5%，实际计算时换算为 0.05。
状态点击结果
  1. 币对配置列表中的“风险预警”为可点击结果标签。
  2. 点击后打开结果弹窗，展示：平台最大可亏损额、当前多仓亏损、当前空仓亏损、风险比率、当前优先ADL方向、当前状态、30天已ADL次数、状态判定公式。
  3. “正常”状态仅展示结果标签，不弹出结果说明。
操作列
  1. 编辑：进入当前币对的配置编辑页面。
  2. 币对持仓用户：跳转到该币对的持仓用户列表，并自动带入交易对筛选条件。
  3. 减仓详情：跳转到 ADL减仓列表，并自动带入当前币对筛选条件，用于查看该币对下用户减仓记录。
分页
  1. 当币对配置总数大于 8 条时分页展示。
  2. 每页固定展示 8 条。
  3. 支持上一页和下一页切换。
配置编辑页面
  1. 本页为独立配置编辑页面，不使用弹窗。
  2. 本页展示完整配置字段、风险参考说明、风控率与预计收益参考值。
  3. 本页用于承载长字段和多参数录入场景。
输入项逐项定义
  1. 交易对：下拉单选，取值范围以后端支持的币对配置列表为准，保存后回写当前币对配置。
  2. 平台最大可亏损额(USDT)：仅支持大于 0 的数值，保存后作为平台总亏损阈值参与风险比率计算。
  3. 多仓用户破产价偏移比例(%)：支持最多 2 位小数，必须大于等于 0，保存后按“市价 × (1 - 偏移比例)”参与多仓破产价推导。
  4. 空仓用户破产价偏移比例(%)：支持最多 2 位小数，必须大于等于 0，保存后按“市价 × (1 + 偏移比例)”参与空仓破产价推导。
  5. ADL减仓持仓单次比例：下拉单选，支持“全部 / 按比例”；选择“按比例”后，展示比例输入框。
  6. 单次减仓比例(%)：仅在“按比例”时必填，支持最多 2 位小数，取值范围大于 0 且小于等于 100。
  7. 重置用户累计数据：单选项，支持日、周、月、总，保存后回写当前统计周期配置。
  8. 点击“保存配置”后，列表与顶部概览使用保存后的值刷新；点击“返回列表”不保存未确认修改。
页面价格与数量来源
  1. 配置编辑页中涉及交易对、市价推导、破产价偏移比例等参数，以后端币对配置为准。
  2. 配置编辑页中的当前多仓亏损、当前空仓亏损、最小开仓数量不由前端录入，统一以后端风控与币对参数返回结果为准。
  3. 后续页面展示的持仓数量、开仓均价、标记价格、当前价及相关价格结果，以后端返回的该币对配置与实时数据为准。
  4. 前端不自行重算基础行情口径。
ADL减仓持仓单次比例
  1. “全部”表示单次 ADL 时，对当前用户当前币对当前方向下的可减仓持仓全部减仓。
  2. “按比例”表示单次减仓数量 = 当前可减仓持仓数量 × 单次减仓比例。
  3. 若计算结果小于该币对最小开仓数量，则按全部减仓处理。
  4. 最小开仓数量与最终可减仓数量口径以后端返回为准，前端仅展示当前配置。
多仓用户破产价偏移比例(%) / 空仓用户破产价偏移比例(%)
  1. 两项配置均用于按触发时市场价格推导用户破产价。
  2. 多仓用户破产价 = 市价 × (1 - 多仓用户破产价偏移比例)。
  3. 空仓用户破产价 = 市价 × (1 + 空仓用户破产价偏移比例)。
  4. 配置值按百分比理解，例如输入 5 表示 5%，实际计算时换算为 0.05。
保存与返回
  1. 点击“保存配置”后，回写当前交易对配置。
  2. 保存成功后，刷新币对配置列表与顶部数据概览。
  3. 点击“返回列表”返回币对配置列表页，不保存未确认修改。
当前风控率 / 预计收益 / 重置
  1. 当前风控率：表示根据当前配置值计算出的风险参考比例，最多支持 2 位小数。
  2. 预计收益：表示基于当前配置值推导的参考收益金额，单位为 USDT，最多展示 8 位小数。
  3. 点击“重置”后，当前编辑表单恢复为本次进入页面时的原始配置值，不保存未确认修改。
币对持仓用户列表
  1. 本页展示某个交易对下当前存在持仓的用户列表。
  2. 本页用于快速查看持仓风险敞口。
  3. 支持按交易对、用户ID、用户账号筛选，并分页展示。
  4. 列表排序口径与 ADL 减仓列表保持一致，按全局综合排序值从高到低排序。
筛选输入项定义
  1. 交易对：下拉单选，默认全部；选中后仅展示对应币对持仓用户。
  2. 用户ID：文本输入，按包含关系匹配；空值表示不过滤。
  3. 用户账号：文本输入，按包含关系匹配；空值表示不过滤。
  4. 点击“查询”后，列表按条件过滤并回到第一页。
  5. 点击“重置”后，交易对恢复全部、用户ID和用户账号清空，并重新加载第一页。
持仓数量(USDT)
  1. 该字段表示用户在该交易对下的持仓名义价值，按 USDT 计价。
  2. 该字段包含用户当前币对下的全仓持仓与逐仓持仓。
  3. 该字段以后端币对配置和后端持仓结果为准。
  4. 前端仅按接口返回结果展示，不自行调整基础持仓数量口径。
保证金模式 / 持仓方向 / 杠杆 / 最后更新时间
  1. 保证金模式：取值为“全仓 / 逐仓”，以后端持仓返回结果为准。
  2. 持仓方向：取值为“多仓 / 空仓”，以后端持仓方向字段为准。
  3. 杠杆：表示该用户当前持仓使用的杠杆倍数，以后端返回结果为准。
  4. 最后更新时间：表示该条持仓记录最近一次被风控或持仓同步刷新到页面的时间，格式为 `YYYY-MM-DD HH:mm:ss`。
开仓均价 / 标记价格
  1. 开仓均价、标记价格以及相关详情页中的当前价，均以后端该币对配置和实时行情返回结果为准。
  2. 前端不以本地演示数据重新推导真实行情，仅负责展示与交互联动。
未实现盈亏(USDT)
  1. 该字段表示当前持仓的未实现盈亏，按 USDT 计价。
  2. 大于 0 表示盈利，小于 0 表示亏损。
  3. 最多保留 8 位小数，末尾为 0 的小数位不展示。
  4. 该字段以后端返回结果为准。
分数与排序
  1. 币对持仓用户列表与 ADL 减仓列表使用同一套全局排序公式。
  2. 盈亏百分比 = 未实现收益 ÷ 绝对值(名目仓位)。
  3. 有效杠杆 = 绝对值(名目仓位) ÷ (钱包余额 + 未实现收益)；当钱包余额 + 未实现收益小于等于 0 时，分母按 1 处理。
  4. 若盈亏百分比大于等于 0，则基础排序值 = 盈亏百分比 × 有效杠杆；若盈亏百分比小于 0，则基础排序值 = 盈亏百分比 ÷ 有效杠杆。
  5. 次数惩罚分位值 = (用户总数 - 30天ADL减仓次数排名 + 1) ÷ 用户总数。
  6. 金额惩罚分位值 = (用户总数 - 30天ADL减仓金额排名 + 1) ÷ 用户总数。
  7. 公平调节系数 = 1 + 0.35 × 次数惩罚分位值 + 0.15 × 金额惩罚分位值。
  8. 基础排序值大于等于 0 时，综合排序值 = 基础排序值 ÷ 公平调节系数；基础排序值小于 0 时，综合排序值 = 基础排序值 × 公平调节系数。
  9. 30天ADL减仓次数越多、30天ADL减仓金额越大，则公平调节系数越大，排序更可能向后延。
  10. 列表中的“分数”字段即综合排序值，最多展示 8 位小数；点击分数可查看相关计算参数与计算过程。
  11. 页面按分数从高到低排序；若分数相同，则按最后更新时间倒序，再按用户ID倒序。
自动ADL异常处理
  1. 自动ADL先按当前优先方向和综合排序值，从高到低选择候选用户。
  2. 若候选用户存在挂单，且剩余可平部分小于“持仓数量 × 币对配置中的单次减仓比例”对应结果，则系统需先撤销该用户相关挂单，再继续执行自动ADL。
  3. 若当前候选持仓状态为“已完成”，则视为本次候选无效，系统自动顺延排序第二名、第三名，直到自动ADL成功或当前候选池耗尽。
  4. 自动ADL成功后，系统需再次按最新亏损方向、最新分数排名和最新候选持仓结果，判断是否需要执行第二次自动ADL，以及下一次应执行的方向和候选用户。
  5. 上述顺延、撤单、二次判断逻辑均属于执行链路处理，不改变分数公式本身；成功落库的“ADL时排序值”仅记录实际执行成功的那一名用户。
操作-用户详情
  1. 点击“用户详情”后，页面跳转至“用户详情”页。
  2. 跳转时传递参数 `userId`；若入口来源于币对持仓用户列表或减仓列表，则同时保留当前入口页作为返回来源。
  3. 跳转时默认传递 `tab = orders`，即默认打开“用户减仓订单记录”页签。
  4. 详情页顶部汇总信息、当前持仓列表、订单记录、成交记录均按 `userId` 聚合展示。
  5. 若该用户暂无减仓记录，则订单记录与成交记录展示空列表；若暂无当前持仓，则当前持仓列表展示空列表。
操作-手动ADL减仓
  1. 点击“手动ADL减仓”后，在当前页面打开弹窗。
  2. 弹窗字段包含：破产价、当前价、持仓数量、持仓方向、持仓均价、平仓数量、平仓后用户盈亏显示、谷歌验证码、确认、取消。
  3. 破产价为可输入字段；其余展示字段按当前持仓数据回填。
  4. 当前价、持仓数量、持仓方向、持仓均价以后端币对配置与后端持仓结果为准。
  5. 平仓后用户盈亏显示实时联动计算：多仓按（破产价 - 持仓均价）× 平仓数量；空仓按（持仓均价 - 破产价）× 平仓数量。
  6. 若当前持仓存在挂单，且剩余可平部分小于“持仓数量 × 币对配置中的单次减仓比例”对应结果，则手动ADL确认时需先撤销该用户挂单，再继续执行ADL。
  7. 若当前持仓状态为“已完成”，则前端直接提示“此持仓状态为已完成，不可ADL”，不再打开或执行手动ADL。
  8. 确认成功后，更新持仓用户列表、减仓列表、ADL当前用户列表和用户详情演示数据。
手动ADL输入项定义
  1. 破产价：支持输入大于 0 的价格值，最多 2 位小数，作为本次手动 ADL 的价格输入参与盈亏计算。
  2. 平仓数量：支持输入大于 0 且不大于当前持仓数量的数值。
  3. 谷歌验证码：仅支持 6 位纯数字，输入不满足规则时确认失败。
  4. 若校验到挂单导致剩余可平部分不足，系统先执行撤单，再继续执行本次手动ADL；若撤单后仍不满足执行条件，则提示失败且不落库。
  5. 点击“确认”后，若输入合法，则刷新持仓用户列表、减仓列表、ADL当前用户列表与用户详情；若输入不合法，则前端提示错误信息且不更新结果。
手动ADL弹窗展示字段
  1. 当前价：表示当前币对的实时价格，以后端行情返回为准。
  2. 持仓数量：表示当前用户在该币对下的可减仓持仓数量，以后端持仓结果为准。
  3. 持仓方向：取值为“多仓 / 空仓”。
  4. 持仓均价：表示当前持仓的开仓均价。
  5. 平仓后用户盈亏显示：表示按当前输入的破产价、平仓数量、持仓方向、持仓均价计算出的本次减仓盈亏结果，金额最多展示 8 位小数。
  6. 错误提示区域：用于展示验证码不合法、平仓数量超限或必填项为空等校验失败原因。
分页
  1. 当币对持仓用户总数大于 8 条时分页展示。
  2. 每页固定展示 8 条。
  3. 支持上一页和下一页切换。
减仓列表
  1. 本页展示发生过 ADL 盈利减仓的用户维度汇总列表。
  2. 支持按交易对、用户ID、类型、开始时间、结束时间筛选，并支持分页展示。
  3. 列表展示字段包括：类型、减仓前用户未实现盈亏、减仓前盈利率、此次减仓盈利率、减仓已实现盈亏、ADL时排序值、最新减仓时间。
  4. 减仓次数、30天ADL减仓次数、30天ADL减仓金额不在本列表展示，但仍用于详情页、统计口径和排序计算。
  5. 列表默认按最新减仓时间倒序排序；若最新减仓时间相同，则按 ADL时排序值倒序，再按用户ID倒序。
筛选输入项定义
  1. 交易对：下拉单选，默认全部；选中后仅展示该币对减仓记录。
  2. 用户ID：文本输入，按包含关系匹配；空值表示不过滤。
  3. 类型：下拉单选，支持“全部类型 / 自动ADL / 手动ADL”。
  4. 开始时间：按最新减仓时间大于等于开始时间过滤。
  5. 结束时间：按最新减仓时间小于等于结束时间过滤。
  6. 点击“查询”后，列表按条件过滤并回到第一页。
  7. 点击“重置”后，交易对恢复全部、用户ID清空、类型恢复全部类型、开始时间和结束时间清空，并重新加载第一页。
全局排序规则
  1. ADL 减仓用户列表按全局候选用户池统一计算排序。
  2. 页面筛选仅影响展示结果，不改变用户在当前排序中的全局位置。
  3. 盈亏百分比 = 未实现收益 ÷ 绝对值(名目仓位)。
  4. 有效杠杆 = 绝对值(名目仓位) ÷ (钱包余额 + 未实现收益)；当钱包余额 + 未实现收益小于等于 0 时，分母按 1 处理。
  5. 盈亏百分比大于等于 0 时，基础排序值 = 盈亏百分比 × 有效杠杆；盈亏百分比小于 0 时，基础排序值 = 盈亏百分比 ÷ 有效杠杆。
  6. 杠杆盈亏分位数 = 用户排名 ÷ 用户总数，其中用户排名按基础排序值从高到低排序，排名 1 为最高优先级。
30天ADL减仓次数 / 30天ADL减仓金额
  1. 30天ADL减仓次数：指当前时间向前滚动 30 个自然日内，该用户累计被 ADL 的次数。
  2. 30天ADL减仓金额：指同一时间范围内，该用户累计被 ADL 的减仓金额绝对值总和，单位为 USDT。
公平修正公式
  1. 系统在 ADL 触发时，会按基础排序值与公平修正公式计算当次 ADL 的排序值，并将结果快照写入减仓记录。
  2. 次数惩罚分位值 = (用户总数 - 30天ADL减仓次数排名 + 1) ÷ 用户总数；次数排名按 30 天 ADL 减仓次数从高到低排序。
  3. 金额惩罚分位值 = (用户总数 - 30天ADL减仓金额排名 + 1) ÷ 用户总数；金额排名按 30 天 ADL 减仓金额从高到低排序。
  4. 公平调节系数 = 1 + 0.35 × 次数惩罚分位值 + 0.15 × 金额惩罚分位值。
  5. 基础排序值大于等于 0 时，综合排序值 = 基础排序值 ÷ 公平调节系数；基础排序值小于 0 时，综合排序值 = 基础排序值 × 公平调节系数。
  6. 示例：若用户总数为 10，某用户 30天ADL减仓次数排名第 1，30天ADL减仓金额排名第 1，则次数惩罚分位值 = 1，金额惩罚分位值 = 1，公平调节系数 = 1.5。
  7. 若该用户基础排序值 = 0.40645161，则综合排序值 = 0.40645161 ÷ 1.5 = 0.27096774。
  8. 次数越多、金额越大，则公平调节系数越大，排序越可能向后延。
  9. 减仓列表展示的“ADL时排序值”即当次 ADL 触发时落库的排序快照值，不随当前页面实时排序重新计算。
  10. 点击“ADL时排序值”可查看参与该次排序的相关计算参数与公式。
用户账号 / 类型 / 减仓次数 / ADL时排序值 / 最新减仓时间
  1. 用户账号：表示平台内该用户的登录账号或展示账号。
  2. 类型：固定取值为“自动ADL / 手动ADL”。
  3. 减仓次数：表示该用户在当前交易对下累计被执行 ADL 减仓的次数，展示为整数；该字段当前不在减仓列表中展示。
  4. ADL时排序值：表示该条减仓记录在实际触发 ADL 时计算并落库的排序值快照，最多展示 8 位小数。
  5. 最新减仓时间：表示该用户最近一次发生 ADL 减仓的时间，格式为 `YYYY-MM-DD HH:mm:ss`，也是减仓列表默认第一排序字段。
减仓前用户未实现盈亏 / 减仓前盈利率 / 此次减仓盈利率
  1. 减仓前用户未实现盈亏：表示该次 ADL 触发前，用户在该持仓上的未实现盈亏金额，单位为 USDT。
  2. 减仓前盈利率 = 减仓前用户未实现盈亏 ÷ 减仓前持仓数量 × 100%。
  3. 此次减仓盈利率 = 此次减仓盈亏 ÷ 此次减仓数量 × 100%。
  4. 此次减仓盈亏的计算方向与手动ADL减仓弹窗保持一致：多仓按（减仓时价格 - 持仓均价）× 此次减仓数量，空仓按（持仓均价 - 减仓时价格）× 此次减仓数量。
  5. 减仓列表优先展示最新一笔减仓订单记录中的上述三个值；若订单明细不存在，则可按当前用户汇总持仓数据回退计算展示。
减仓已实现盈亏(USDT)
  1. 该字段表示该用户在该交易对下因 ADL 减仓产生的累计已实现盈亏。
  2. 大于 0 表示盈利，小于 0 表示亏损。
跳转到详情
  1. 点击“订单记录”按钮时，执行跳转步骤：先取当前行的 `交易对` 和 `用户ID`，拼接得到 `activeUserKey = 交易对 + "|" + 用户ID`。
  2. 点击“订单记录”按钮时，传递参数 `activeUserKey` 与 `tab = orders`。
  3. 点击“成交记录”按钮时，传递参数 `activeUserKey` 与 `tab = fills`。
  4. 进入详情页后，顶部汇总按 `activeUserKey` 回查用户汇总数据生成。
  5. 进入详情页后，页签默认按 `tab` 参数激活；`orders` 对应“用户减仓订单记录”，`fills` 对应“用户减仓成交记录”。
  6. 切换详情页时，当前详情页分页重置为第 1 页。
  7. 日期筛选条件如果已有输入值，则继续沿用；若为空，则默认不过滤。
  8. 若当前用户在当前交易对下无对应记录，则详情页展示空列表，不报错、不跳回上一页。
分页
  1. 当减仓列表总数大于 8 条时分页展示。
  2. 每页固定展示 8 条。
  3. 支持上一页和下一页切换。
ADL当前用户列表
  1. 本页按用户维度展示当前进入 ADL 观察范围的用户列表。
  2. 列表字段包含：用户UID、当前持仓总额、持仓未实现盈利总额、用户历史持仓数、用户已实现盈利总额。
  3. 本页默认按持仓未实现盈利总额倒序排列；若相同，则按最近更新时间倒序，再按用户UID倒序。
字段定义
  1. 当前持仓总额：表示该用户当前所有币对、所有方向持仓的名义价值总和，单位为 USDT。
  2. 持仓未实现盈利总额：表示该用户当前所有持仓未实现盈亏的汇总结果，单位为 USDT。
  3. 用户历史持仓数：表示该用户历史上出现过持仓或发生过 ADL 记录的交易对数量，按去重后的交易对数统计。
  4. 用户已实现盈利总额：表示该用户历史 ADL 已实现盈亏的累计结果，单位为 USDT。

分页

  3. 支持上一页和下一页切换。
用户详情
  1. 本页用于展示某一用户维度的 ADL 详情信息。
  2. 页面顶部展示用户汇总信息：用户UID、用户账号、当前持仓总额、持仓未实现盈利总额、用户历史持仓数、用户已实现盈利总额、最近更新时间。
  3. 页面中部新增“用户当前持仓列表”，展示该用户当前所有币对持仓，并支持在对应持仓上执行手动ADL减仓。
  4. 顶部用户统计数据跟随页面顶部“日 / 周 / 月 / 总”统计维度切换。
  5. 下方通过 Tab 切换展示订单记录与成交记录，并支持按日期区间筛选。

  7. 订单记录与成交记录默认均按记录时间倒序排列，最新记录优先展示。
顶部汇总字段定义
  1. 用户UID：表示当前查看明细所属的唯一用户标识。
  2. 用户账号：表示该用户的展示账号。
  3. 当前持仓总额：表示该用户当前所有持仓价值总和，单位为 USDT。
  4. 持仓未实现盈利总额：表示该用户当前所有持仓未实现盈亏汇总结果，单位为 USDT。
  5. 用户历史持仓数：表示该用户历史上出现过持仓或发生过 ADL 的交易对数量。
  6. 用户已实现盈利总额：表示该用户按顶部当前统计维度汇总得到的 ADL 已实现盈亏金额。
  7. 最近更新时间：表示当前统计维度或当前持仓数据内最近一次更新时间，格式为 `YYYY-MM-DD HH:mm:ss`。
  8. 若顶部切换统计维度，则上述用户统计字段同步切换到对应周期口径。
用户当前持仓列表
  1. 本列表展示该用户当前所有币对持仓。
  2. 字段包括：交易对、保证金模式、持仓方向、持仓数量、开仓均价、标记价格、未实现盈亏、杠杆、最后更新时间、操作。

  4. 操作中的“手动ADL减仓”直接打开对应持仓的手动ADL减仓弹窗；若当前持仓状态为“已完成”，则提示用户不可ADL。
  5. 列表默认按最后更新时间倒序展示；若相同，则按交易对倒序展示。
日期筛选输入项定义
  1. 日期开始：按记录日期大于等于开始日期过滤。
  2. 日期结束：按记录日期小于等于结束日期过滤。
  3. 开始日期和结束日期均为空时，默认不过滤。
  4. 点击“查询”后，按日期范围刷新当前 Tab 列表，并从第一页开始展示。
  5. 点击“重置”后，清空开始日期与结束日期，并重新加载当前 Tab 第一页。
订单记录
  1. 订单记录展示字段：交易对、减仓时间、开仓方向、减仓数量(USDT)、减仓时实时价格、订单成交均价、减仓前用户未实现盈亏(USDT)、减仓前盈利率(%)、此次减仓盈利率(%)、减仓盈亏(USDT)、订单状态。
  2. 减仓时实时价格、订单成交均价、减仓数量以后端币对配置与订单返回结果为准。
  3. 减仓前用户未实现盈亏表示该笔订单触发前，用户在该持仓上的未实现盈亏金额。
  4. 减仓前盈利率 = 减仓前用户未实现盈亏 ÷ 减仓前持仓数量 × 100%。
  5. 此次减仓盈利率 = 此次减仓盈亏 ÷ 此次减仓数量 × 100%。
  6. 此次减仓盈亏计算方向与手动ADL减仓弹窗一致：多仓按（减仓时价格 - 持仓均价）× 此次减仓数量；空仓按（持仓均价 - 减仓时价格）× 此次减仓数量。
  7. 订单记录默认按减仓时间倒序排列。
  8. 涉及盈亏金额与盈利率展示时，最多保留 8 位小数，末尾为 0 的小数位不展示。
成交记录
  1. 成交记录展示字段：成交ID、订单ID、交易对、成交时间、成交数量(USDT)、成交价格、成交金额(USDT)、手续费(USDT)、成交盈亏(USDT)。
  2. 成交价格、成交数量、成交金额以后端成交回报为准。
  3. 涉及盈亏与金额字段时，最多保留 8 位小数，末尾为 0 的小数位不展示。
订单状态 / 手续费
  1. 订单状态：表示该减仓订单当前处理结果，原型演示中可展示为“已完成 / 撤单后已完成 / 处理中 / 已取消”等枚举值，实际取值以后端订单状态返回为准。
  2. 手续费：表示对应成交记录产生的手续费金额，单位为 USDT，最多展示 8 位小数，末尾为 0 的小数位不展示。
分页
  1. 当详情明细记录总数大于 8 条时分页展示。
  2. 每页固定展示 8 条。
  3. 支持上一页和下一页切换。
结果弹窗字段定义
  1. 风险预警结果弹窗中的币对、平台最大可亏损额、当前多仓亏损、当前空仓亏损、风险比率、当前优先ADL方向、当前状态、30天已ADL次数，分别对应当前币对配置表中的交易对、平台总亏损阈值、多仓当前亏损、空仓当前亏损、总亏损与阈值的比率、当前优先处理方向、状态结果、近30天ADL次数。
  2. 分数计算详情弹窗中的名目仓位、未实现收益、钱包余额、盈亏百分比、有效杠杆、基础排序值、次数惩罚分位值、金额惩罚分位值、公平调节系数、综合排序值，分别对应排序公式中的原始入参、中间计算结果与最终输出结果。
  3. 两个结果弹窗均用于开发和测试逐项核对排序链路与风控链路。

风险预警结果

展示该币对当前状态的计算结果与判定说明，便于业务、开发和测试核对预警来源。

手动ADL减仓

在当前页对持仓用户发起手动 ADL 减仓。确认后同步刷新持仓用户列表、减仓列表和对应详情页演示数据。

平仓数量默认按 USDT 口径输入，平仓数量不能大于当前持仓数量。平仓后用户盈亏显示按持仓方向计算：多仓按（破产价 - 持仓均价）× 平仓数量计算，空仓按（持仓均价 - 破产价）× 平仓数量计算。

分数计算详情

展示当前用户分数的相关计算参数与公式展开，便于开发、测试和业务核对排序结果。
